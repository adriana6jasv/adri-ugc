# Videos de Adri

Reemplaza los tres archivos vacíos de esta carpeta por los MP4 reales (H.264 + AAC, 9:16, idealmente 1080 × 1920):

- video-problem-solution.mp4
- video-voiceover.mp4
- video-real-mom-storytelling.mp4

Los archivos vacíos son marcadores; no se publican ni se intentan reproducir. El build activa cada reproductor automáticamente cuando detecta un MP4 válido. Las portadas se configuran en src/content.mjs.

Subtítulos opcionales en WebVTT, recomendados para accesibilidad: problem-solution.es.vtt, voiceover.es.vtt y real-mom.es.vtt. No se incluyen subtítulos ficticios.
